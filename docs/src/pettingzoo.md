# Petting Zoo

PettingZoo is a small Streamlit app that allows users to visualize and interact 
with the available algorithms in MetaZoo. It provides a user-friendly interface
to explore different optimization functions and their characteristics.

## Web App

The PettingZoo app is hosted on Cloud and can be accessed via the following link:
[PettingZoo Cloud](https://pettingzoo.unknowable.xyz)

## Local Setup

To run the PettingZoo app, use the following command:

```bash
cd pettingzoo
uv run streamlit run app.py
```
