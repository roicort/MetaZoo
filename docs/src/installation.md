# Installation

As this is a beta release, it's recommended to install MetaZoo in a virtual environment. 
I really recomend using uv package manager.

To install MetaZoo from GitHub.

```bash
 uv add "metazoo @ git+https://github.com/roicort/MetaZoo"
```

Or, if you are developing locally, clone the repository and install with:

```bash
git clone https://github.com/roicort/MetaZoo.git
cd playground
uv run
```
